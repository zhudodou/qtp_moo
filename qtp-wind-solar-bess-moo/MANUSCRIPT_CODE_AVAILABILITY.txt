Code Availability

The code used to implement the spatial multi-objective optimization framework is available at GitHub: https://github.com/AUTHOR_INPUT_NEEDED/qtp-wind-solar-bess-moo. The repository includes the core Python implementation of the binary spatial multi-objective optimization framework, the NSGA-II, MOEA/D, and SPEA2-style selection procedures, a command-line script for reproducing the optimization experiments from processed NetCDF inputs, and a cleaned provenance notebook. The processed geospatial input files are not included in the code repository because they are derived from multiple external datasets; the required input variables and directory structure are documented in the repository.
