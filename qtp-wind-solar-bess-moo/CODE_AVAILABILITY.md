# Code Availability

The code used to implement the spatial multi-objective optimization framework
is available in this repository. The command-line implementation is provided in
`src/qtp_moo/` and `scripts/run_experiment.py`; a cleaned provenance notebook is
provided in `notebooks/666_algorithm_clean.ipynb`.

The processed NetCDF input files used in the manuscript are not included in the
GitHub repository because they are derived from multiple external geospatial
and energy datasets. The expected data structure and variable names are
documented in `data/README.md`.
